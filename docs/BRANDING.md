# DevPanel brand assets

## Primary assets

- `static/branding/devpanel-mark.svg` — square application mark for compact UI and favicon use.
- `static/branding/devpanel-logo.svg` — horizontal wordmark for documentation and marketing surfaces.
- `src-tauri/icons/` — generated desktop and Windows package icons.
- `static/favicon.svg` and `static/favicon.png` — web favicons.

## Visual system

The DevPanel mark combines a layered application panel with a terminal prompt. It represents local runtime control and developer workflow without relying on third-party brand marks.

| Token | Value | Use |
| --- | --- | --- |
| Primary blue | `#2563EB` | Main product identity and interactive emphasis |
| Deep navy | `#1E3A8A` | Icon depth and dark-surface contrast |
| Cyan | `#06B6D4` | Terminal accent and secondary highlight |
| Cloud | `#F8FAFC` | Panel surface and high-contrast detail |
| Slate | `#64748B` | Supporting wordmark text |

## Usage

Use the mark with its rounded-square background intact. Do not recolor, stretch, crop, combine it with another product mark, or use it to imply endorsement.

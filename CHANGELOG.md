# Changelog

## 0.2.0-beta.1 - 2026-07-27

First public beta release.

- Local workspace management for WordPress and common PHP projects.
- Portable runtime management for Apache, Nginx, PHP, databases, caches, and local mail tooling.
- Independent Apache and Nginx bind ports with conflict resolution.
- WordPress core, plugin, theme, cache, health, security, and performance tools through WP-CLI.
- Windows build, installer, and pre-release automation.
